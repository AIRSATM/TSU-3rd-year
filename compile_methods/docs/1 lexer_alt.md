# Лексический анализатор (C#)

**Файлы:** [`src/MiniLang/Lexing/Token.cs`](../src/MiniLang/Lexing/Token.cs),
[`src/MiniLang/Lexing/Lexer.cs`](../src/MiniLang/Lexing/Lexer.cs).

`Lexer` — табличный ДКА. Переходы выбираются по паре
`(состояние, класс символа) → (следующее состояние, действие)`.

## 1. Состояния и классы символов

### `LexState`

| Состояние | Описание |
|---|---|
| `Start` | Ожидание лексемы |
| `Ident` | Идентификатор |
| `Int` | Целое число |
| `Real` | Дробная часть |
| `Dot` | Точка после целой части |
| `Colon` | После `:` (ожидание `=`) |
| `Lt` / `Gt` | После `<` / `>` |
| `Slash` | После `/` (проверка `//`) |
| `Comment` | Внутри `//`-комментария |

### `CharClass`

| Класс | Символы | Класс | Символы |
|---|---|---|---|
| `Letter` | `a–z A–Z _` | `Star` | `*` |
| `Digit` | `0–9` | `Slash` | `/` |
| `Dot` | `.` | `LParen`/`RParen` | `(` `)` |
| `Colon` | `:` | `LBrack`/`RBrack` | `[` `]` |
| `Eq` | `=` | `Semi` | `;` |
| `Lt`/`Gt` | `<` `>` | `Comma` | `,` |
| `Plus`/`Minus` | `+` `-` | `Space` | ` ` `\t` |
| `Newline` | `\n` `\r` | `Eof` | конец ввода |
| `Other` | всё остальное → ошибка | | |

`Classify(int)` отображает символ в `CharClass`.

### Действия (`Action`)

| Действие | Смысл |
|---|---|
| `Accum` | В буфер и к следующему символу |
| `Skip` | Пропустить символ |
| `Emit` | Выдать токен, символ **не** потребляется |
| `EmitC` | Выдать токен и потребить символ |
| `Error` | Лексическая ошибка |

Таблица `TransitionTable[state, class]` заполняется один раз в
`BuildTransitionTable()`: сначала всё = `Error`, затем задаются допустимые переходы.

## 2. Что распознаётся

- **Идентификаторы:** `[A-Za-z_][A-Za-z_0-9]*`.
- **Целые числа:** последовательность цифр, `Value` хранится как `double` (через `long`).
- **Вещественные:** `цифры '.' цифры` (дробная часть обязательна).
- **Ключевые слова:** после распознавания идентификатора сверка со словарём `Keywords`
  (`if` → `TokenType.If`, но `ifx` остаётся `IDENT`).
- **Операторы:** `+ - * / := < > <= >= = <>`.
  Двухсимвольные собираются через `Colon`/`Lt`/`Gt`.
- **Пунктуация:** `( ) [ ] ; ,`.
- **Комментарии:** `//` до конца строки.
- **Координаты:** `Advance()` инкрементирует `_col`, на `\n` сбрасывает `_col` и `++_line`;
  запоминаются в момент начала лексемы.

## 3. Ошибки

Исключение: `LexException(line, col, message)`.
Формат: `Лексическая ошибка [строка L, символ C]: <причина>`.

Примеры причин:
- `недопустимый символ '@'`
- `ожидалась цифра после '.'` (вход `12.`)
- `недопустимый символ` после `:` (ожидался `=`)
- сбой `double.TryParse` (например, переполнение)

## 4. Использование

```csharp
using MiniLang.Lexing;

var tokens = Lexer.Tokenize("x := 1 + 2");
foreach (var t in tokens)
    Console.WriteLine($"{t.Type.Display()} '{t.Lexeme}' @ {t.Line}:{t.Col}");
